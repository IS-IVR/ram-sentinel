# Roadmap

## שלב 0 - שלד ובדיקת בסיס

- [x] יצירת מבנה Solution ופרויקטים.
- [x] מדידת זיכרון באמצעות GlobalMemoryStatusEx.
- [x] חלון Tray בסיסי בעברית.
- [x] רשימת תהליכים לפי Working Set ו-Private Memory.
- [x] הפעלה אוטומטית אופציונלית למשתמש הנוכחי.
- [x] הגדרת GitHub Actions ל-Build ול-Publish.
- [ ] Build ובדיקת הרצה על Windows 11.
- [ ] בדיקה על מחשב עם 4GB / 8GB RAM.

## שלב 1 - יציבות ושימושיות

- [ ] בדיקות יחידה ל-MemoryPressureEvaluator.
- [ ] הגדרות למרווחי דגימה ולספי התראה.
- [ ] הצגת מגמת שימוש (גרף קצר של 5-10 דקות).
- [ ] אפשרות להשתיק התראות לפרק זמן מוגדר.
- [ ] בדיקת צריכת RAM ו-CPU של RAM Sentinel עצמו לאורך 24 שעות.
- [ ] בדיקת התנהגות כאשר תהליך מסתיים בזמן איסוף נתוניו.

## שלב 2 - פעולות סיוע בטוחות

- [ ] הצגת המלצות לפי תהליכים בולטים, בלי להציג כל תהליך כבעיה.
- [ ] פתיחת Task Manager ישירות בלשונית המתאימה ככל שנתמך.
- [ ] אפשרות לסמן אפליקציות משתמש מועדפות להצגה.
- [ ] סגירה רגילה של אפליקציה רק בעקבות פעולה יזומה של המשתמש, עם אזהרה לשמירת עבודה.
- [ ] אין להוסיף סיום כפוי או ניקוי Cache אוטומטי.

## שלב 3 - הפצה

- [ ] Publish עצמאי x64.
- [ ] בדיקת SmartScreen וחתימת קוד אם יוחלט להפיץ לציבור.
- [ ] מתקין והסרה נקייה.
- [ ] עדכון גרסה רק לאחר הוספת מנגנון אמין ומאובטח.

## תנאי קבלה ל-MVP

- האפליקציה מתחילה בשקט באזור ההתראות.
- ניטור הזיכרון לא גורם לקפיצות CPU מורגשות.
- אין פעולות שמשנות/מסיימות תהליכים ללא אישור.
- התוכנה נשארת יציבה לפחות 24 שעות בבדיקת עומס.
- ניתן לבטל הפעלה אוטומטית ולהסיר את התוכנה בלי להשאיר שירותים או משימות רקע.
