# פרטיות

RAM Sentinel מיועדת לעבוד מקומית בלבד.

- אין חיבור לשרת חיצוני בזמן הריצה.
- אין Analytics, Telemetry, מזהי משתמש או דיווחי קריסה החוצה.
- שמות תהליכים ונתוני זיכרון מוצגים מקומית בלבד.
- לא נאספים נתיבי קבצים, שורות פקודה, כותרות חלונות או תוכן משתמש.
- אין שמירת היסטוריה בגרסה הראשונה.
- הגדרת הפעלה אוטומטית נשמרת במפתח Run של המשתמש הנוכחי בלבד.
- GitHub Actions משמש לבניית הקוד בלבד; הוא אינו חלק מהיישום שרץ במחשב.

כל שינוי עתידי במדיניות זו חייב להיות מתועד ומוצג למשתמש לפני הוספתו.
